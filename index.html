NYC 311 Data Pipeline

Complete

An end-to-end data pipeline that pulls New York City 311 service requests (noise complaints, potholes, and more) and turns them into clean tables ready for analysis.

  • Pulls raw 311 data and loads it into a PostgreSQL database
  • Runs on a schedule with an Airflow DAG, so new data comes in on its own
  • Uses dbt to clean and reshape the data into analysis-ready models
  • Explores trends in a Jupyter notebook

Hospital Readmission Risk

In progress

A machine learning model that predicts which diabetic patients are likely to return to the hospital within 30 days, built on about 101,000 real hospital visits from 130 U.S. hospitals.

  • Cleaned and prepared the data into 80 model-ready columns with no missing values
  • Trained a Random Forest model and handled the imbalance, since only about 11% of patients were readmitted
  • Used SHAP to show which factors pushed each patient's risk up or down
  • Checked the model's findings against my own clinical experience
Result: ROC-AUC of 0.67, with clear charts explaining the drivers behind high-risk and low-risk patients.

Loan Outcome Prediction

Complete

A three-person group project for STOR 320, where I wrote all of the code. Using 45,000 loan applications, we predicted each application's outcome and compared a simple, explainable model with a more powerful one.

  • Cleaned the data, including removing applicants with impossible ages (one was listed as 144)
  • Split the data 80/20 and set a baseline: guessing the most common outcome is right 77.8% of the time
  • Compared logistic regression with a 100-tree random forest on the same test set
  • Wrote openly about the limits, like signs the data is synthetic and variables that may leak the answer
Result: The random forest reached 93% accuracy and a 0.98 ROC-AUC, beating logistic regression (85%, 0.86). It also caught 77% of minority-class cases compared with 49%.
